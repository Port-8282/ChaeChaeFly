# 로컬 개발 환경 준비

현재는 폴더·템플릿·문서만 구성했다. 앱 실행 코드와 Compose 파일은 없어 전체 서비스를 실행할 수 없다.

1. 저장소를 clone하고 README·CONTRIBUTING을 읽는다.
2. 개발 시작 전 담당 서비스의 기술 스택·런타임·실행 명령·포트·환경변수를 합의한다.
3. main·dev의 초기 기준과 보호 규칙을 준비한 뒤 최신 dev에서 feature/영역-업무내용 브랜치를 만든다.
4. AI·ML·학습은 각 폴더에서 별도 uv 프로젝트로 초기화한다. 실제 의존성으로 생성한 uv.lock을 함께 공유한다.
5. 서비스별 실행을 확인한 뒤 Dockerfile과 개발용 Compose를 구현한다.
6. 가상 JSON 이벤트 → 계산 → 대시보드 갱신의 통합 흐름을 확인한다.

`.env.example`은 변수 이름 초안이다. 필요한 값·서비스를 확정해 로컬 .env로 사용하며 실제 비밀값은 커밋하지 않는다. 로컬 .venv는 호스트에서 Python을 직접 개발할 때 사용하며 이미지 안에는 복사하지 않는다.

설정 구현 후 로컬 실행에 사용할 파일 조합은 compose.yaml + compose.dev.yaml이다. 지금 실행 가능한 명령으로 오해하지 않도록 구체적인 시작 명령·필요 버전은 구현 후 이 문서에 기록한다.
