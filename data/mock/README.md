# Mock 시연 데이터

공유 가능한 합성 데이터와 순차 전송할 JSON 이벤트를 둔다. 아직 실제 시나리오 파일을 복사하지 않았다. 최종 설계에서는 `master/`에 고정 정보, `scenarios/`에 시작 상태·이벤트, 상위 `data/expected/`에 검산 정답을 둔다. 공통 JSON 규격은 `contracts/schemas/`를 참조한다.

구분할 자료:

- 고정 정보: 선박 제원, 부두 제한, 상품·계약 조건.
- 시작 상태: 대기 선박, 접안 중 선박, 현재 작업 상태.
- 이벤트: 도착·ETA 수정·기상 변화·작업 중단·완료.
- 검증 정답: 특정 입력의 기대 계산 결과. 실행 입력과 별도 파일로 관리하며 모델 특징으로 사용하지 않는다.

시간대·단위·이벤트 순서·시나리오 버전을 명시한다. 팀이 제공받은 데이터는 공유 가능 여부와 컬럼을 확인한 뒤 합성 데이터로 구성한다.

원본 업무자료·DB 덤프·대형 모델·생성 로그는 이 폴더에 넣지 않는다. 이벤트 전송기는 환경 구성 때 구현한다.
