# 운영 스크립트 작성 위치

환경이 확정되면 아래 작업을 스크립트로 구현한다. 현재 실행 스크립트는 없다.

- `deploy`: 지정 릴리스 검증, 서버 공통 잠금, 이미지 pull, 필요한 migration, 대상 서비스 갱신.
- `verify`: DB 연결, API 준비, ML 모델 버전, 전용 Mock 이벤트의 계산·화면 반영 확인.
- `rollback`: 직전 성공 릴리스의 앱 조합을 복구하고 재검증. DB 전체 복원은 자동으로 함께 실행하지 않는다.
- `backup-db`: DB 제품에 맞는 일관된 백업 생성, 별도 저장소 보관, 성공·보관 기간 확인.
- `restore-db`: 지정 백업을 별도 테스트 DB에 복원해 검증. 실제 운영 DB 복원은 데이터 손실 범위를 확인하는 별도 절차로 수행한다.

함수/파일 이름과 사용 언어는 구현 단계에서 정한다. 비밀값을 인자로 출력하거나 로그에 남기지 않는다. 테스트용 이벤트는 실제 데이터를 오염시키지 않는 환경·식별자로 수행한다.
