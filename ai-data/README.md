# AI/Data 영역

- `ai-service/`: 스케줄 탐색·시뮬레이션·규칙 계산·Agent 및 LLM 연동. Compose 서비스 이름은 `ai`.
- `ml-service/`: 검증된 모델을 불러와 하역시간을 예측하는 API. 서비스 이름은 `ml`.
- `training/`: 데이터 준비·모델 학습·평가. 상시 서비스가 아닌 별도 작업.

AI와 ML은 각각 uv 프로젝트로 관리한다. 학습 의존성은 추론 환경과 분리한다. ML의 예측값은 스케줄 계산의 입력이며, 체선료 금액은 계약 규칙 Tool로 계산한다.

학습 산출물을 Git에 직접 넣거나 실행 중인 모델 파일을 덮어쓰지 않는다. 검증 모델의 버전·해시·전처리 규격을 고정하고 ML 이미지에 포함해 배포한다.
