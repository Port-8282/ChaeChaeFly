# AI/Data 영역

- `ai-service/`: 스케줄 탐색·시뮬레이션·규칙 계산·Agent 및 LLM 연동. Compose 서비스 이름은 `ai`.
- `ml-service/`: 검증된 모델을 불러와 하역시간을 예측하는 API. 서비스 이름은 `ml`.
- `training/`: 향후 데이터 준비·모델 학습·평가 위치. 현재 환경 구성은 보류하고 폴더만 유지한다.

AI와 ML은 각각 독립된 uv 프로젝트로 구성했고 FastAPI 상태 확인 API와 Dockerfile을 추가했다. 현재 API는 프로세스 상태만 응답하며 최적화·추론 기능은 구현 전이다. Python 3.12.13을 사용하며 각 폴더에서 `uv sync --locked`로 설치한다. 자세한 절차는 [로컬 개발 안내](../docs/infra/local-setup.md)를 따른다. 학습 환경은 필요할 때 추론과 별도로 구성한다. ML의 예측값은 스케줄 계산의 입력이며, 체선료 금액은 계약 규칙 Tool로 계산한다.

학습 산출물을 Git에 직접 넣거나 실행 중인 모델 파일을 덮어쓰지 않는다. 검증 모델의 버전·해시·전처리 규격을 고정하고 ML 이미지에 포함해 배포한다.
