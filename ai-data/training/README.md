# ML 학습·평가

학습 데이터 준비, 특징 생성, 모델 학습, 평가와 모델 출시 자료를 관리한다. 상시 실행 컨테이너는 아니다.

**현재 학습 환경 구성은 보류한다.** 폴더와 안내 문서만 유지하며 `pyproject.toml`, `uv.lock`, `.venv`는 만들지 않는다. 학습을 이 저장소에서 관리할 시점에 추론 서비스와 별도 uv 프로젝트로 구성한다.

학습 담당자는 검증된 모델 파일·버전, 전처리 방법, 필요한 추론 라이브러리·버전, 입력·출력 형식을 ML 서비스 담당자에게 전달한다.

출시 자료에는 모델 버전, 데이터 버전, 학습 코드 commit, 입력 특징·단위, 전처리 버전, 평가 기준·결과, artifact 위치와 SHA256을 포함한다. 검증을 통과한 자료로 Jenkins 모델 출시 작업을 명시적으로 실행한다.

실제 원본 데이터·대형 모델·실험 결과는 Git 밖에 보관한다. Mock 데이터로 학습·평가한 결과를 현업 데이터 성능으로 표현하지 않는다.
